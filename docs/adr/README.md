# Decisions

One file per decision, numbered in the order they were made, never renumbered.
`0000-template.md` is the shape; copy it.

A decision gets a file when it would be expensive to reverse, when a reasonable
person would have chosen differently, or when we will otherwise have the same
argument again in six months. Choosing a date formatting library does not need
one. Choosing where the queue lives does.

The decisions here are also summarised in chapter 29 of `architecture.md`, and
the two must agree. When a decision is replaced, do not edit the old file beyond
its status line — write a new one and point the old `Status` at it. The history
is the value.

`.claude/skills/writing-an-adr` has the process, and `/adr` starts one.
