# Incidents

One file per incident, named `YYYY-MM-DD-short-name.md`. Write it the day it
happens, while you still remember the order things went wrong in.

Five headings and nothing else: **what the couple saw**, **when**, **what
actually broke**, **how it was fixed**, **what stops it happening again**. The
last one is the only one that matters, and it should link to a commit or an ADR,
not to a good intention.

No blame, no adjectives, and no "lessons learned" section.
